操作说明

键盘 + 鼠标（电脑）

W A S D前进 / 左移 / 后退 / 右移（开车：W 油门、S 刹车倒车、A D 转向）
Shift跑步（开车时：加速）
空格跳跃（开车时：手刹；飞行时：上升）
鼠标环顾四周（点击画面进入/锁定鼠标）
B 或 鼠标左键破坏准星指着的方块（按住连续破坏）
Q 或 鼠标右键爆破：炸掉周围一大片（有冷却），悬空的楼体会塌落
J上车 / 下车（靠近汽车 6 米内）；在直升机里则为离开
U召唤直升机（飞到你身边降落），或在近处登机
E离开直升机（需接近地面）
V切换第一人称 / 第三人称
F飞行模式开关（空格上升、C 下降、Shift 加速）
T切换时间：实时 → 清晨 → 正午 → 黄昏 → 深夜
Y切换天气：实时 → 晴 → 多云 → 雨 → 雾 → 雪
R回到出生点
H / Esc帮助 / 暂停

触屏（手机 / 平板）

左下摇杆移动（推到底自动奔跑）；屏幕空白处滑动转视角；右下按钮：跳、破坏（按住连破）、爆破、上/下车、直升机、跑（切换）、视角、飞行、时间、天气。

小贴士

  • 地图是真实的 OpenStreetMap 数据：建筑轮廓、道路、河道、绿地都对应现实位置，右上角小地图随你转向。没有标注高度的楼是按类型估算的。
  • 开车撞建筑速度够快会直接撞出一个洞；路上的 NPC 车辆也可以被撞开。炸掉承重墙，上面的楼体会塌下来。
  • 按 U 召唤直升机，降落后再按 U 登机。WASD 飞、空格上升、C 下降、Shift 加速，碰到楼会弹开。E 或 J 离开。
  • 出生点在星澜里（西兴路 2333 号）附近。西部还能看到滨江区政府一带。
  • HUD 会显示杭州本地时间和 Open-Meteo 的实时天气（气温、云量、降水、风）；雨/雪/雾/天空会跟着变。断网时按晴天处理。
  • 晚上附近会有手电 / 车灯，窗户会亮起来。
